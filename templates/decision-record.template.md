## ADR-0001：采用 GitHub 主仓 + Gitee 镜像

| 项 | 内容 |
| --- | --- |
| 状态 | 已接受 |
| 日期 | 2026-09-18 |

### 背景

赛事手册第 4 步要求 GitHub 公开仓库 + MIT License，且在线部署服务多需绑定 GitHub。
但团队成员在国内，GitHub 访问速度不稳定，影响协作效率。

### 决策

采用 GitHub 作为主仓，Gitee 作为单向镜像。

### 理由

1. 满足手册硬性要求（GitHub 公开仓库）
2. 在线部署服务（如 Streamlit Cloud）需绑定 GitHub
3. Gitee 镜像解决国内访问速度问题
4. 单向同步（GitHub → Gitee）避免循环拉取与冲突

### 备选方案

| 方案 | 未采用原因 |
| --- | --- |
| 仅 GitHub | 国内访问慢，影响协作 |
| 仅 Gitee | 不满足手册第 4 步要求 |
| 双向同步 | 会产生循环拉取与冲突，10 天周期无精力处理 |

### 影响

正面：兼顾合规与可用性。
代价：多一个远端需维护（可用 Gitee 自动镜像功能降至零维护）。
