## 五、自查清单

### 通用

- [ ] 提交信息符合 `<type>(<scope>): <subject>` 格式
- [ ] 无敏感文件（密钥、`.env`、真实个人数据）被提交
- [ ] 文件编码为 UTF-8 无 BOM，换行为 LF
- [ ] 无「副本」「最终版」类命名

### 按变更类型

- [ ] **JSON 变更**：通过 `schemas/` 中对应 Schema 校验
- [ ] **YAML 变更**：无 Tab 缩进，无硬编码密钥
- [ ] **Markdown 变更**：代码块标注语言，表格格式正确
- [ ] **数据变更**：数据由 `scripts/` 生成，非手工编辑 `data/`
- [ ] **提示词变更**：front matter 的 `version` 与`迭代说明`已同步
- [ ] **Skill 变更**：README 含输入契约、输出格式、失败处理三节
- [ ] **Web 变更**：未引入重型框架，未调用大模型 API

### 合规

- [ ] 学术内容含 `source` 且 URL 真实可访问
- [ ] 若涉及架构取舍，已在 `docs/decisions/` 新增 ADR
- [ ] `CHANGELOG.md` 的 `[未发布]` 段落已更新
