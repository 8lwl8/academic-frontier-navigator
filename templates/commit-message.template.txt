# 提交信息模板
# 依据：SPEC-03 §4 提交信息规范
#
# 格式：<type>(<scope>): <subject>
#
# 【type 取值】
#   feat     新增功能
#   fix      缺陷修复
#   docs     文档变更
#   data     数据文件变更（本项目特有）
#   prompt   提示词变更（本项目特有）
#   refactor 重构（不改行为）
#   chore    杂务（配置、依赖）
#   revert   回滚
#
# 【scope 取值】
#   spec / adr / kb / skill / prompt / web / data / config / log / repo
#
# 【subject 规则】
#   中文描述，不超过 50 字，动词开头，结尾不加句号
#   不要写「修改」「更新」这类无信息量的词
#
# ----------------------------------------
# 示例 1：带 AI 参与的提交（含 footer）
# ----------------------------------------
# feat(skill): 新增简报生成 Skill 的相关性排序
#
# 将检索结果按 high/medium/low 三层排序，
# 高相关内容优先展示，对应架构书四(二)的展示要求。
#
# AI-assisted: LearnBuddy, session-2026-09-20-02
# Refs: 迭代记录 2026-09-20-简报生成Skill.md
# Reviewed-by: <人名>
#
# ----------------------------------------
# 示例 2：数据更新
# ----------------------------------------
# data(briefing): 更新 2026-09-20 每日简报
#
# ----------------------------------------
# 示例 3：提示词迭代
# ----------------------------------------
# prompt(radar): 增加相关性分层与出处标注要求
#
# 明确要求输出三层相关性，且每条必附 source.url。
#
# AI-assisted: LearnBuddy, session-2026-09-20-02
#
# ----------------------------------------
# 【footer 使用规则】
#   Refs:        关联待办/需求
#   Reviewed-by: 有人工复核 AI 产出
#   AI-assisted: 该提交含 AI 生成内容（硬性要求）
#   Breaking:    破坏性变更
