# 残差连接

## 一句话概括

让每一层只需学习「相对输入的增量」而非「完整的映射」，通过恒等捷径把梯度无损地送到浅层，使上百层网络的训练成为可能。

## 核心内容

在残差连接出现之前，网络加深到一定程度后**训练误差反而上升** —— 这不是过拟合（训练误差也上升），而是优化困难：深层网络的梯度在反向传播中反复相乘，容易消失或爆炸，导致浅层几乎收不到有效更新信号。

**残差连接**的改动极为简洁：把子层的输出从 `F(x)` 改为 `F(x) + x`。

```text
原始：  y = F(x)
残差：  y = F(x) + x        # 要求 F 与 x 维度一致
```

**为什么这一改动有效**（三个层次的理由，理解深度递进）：

1. **梯度高速公路**。反向传播时，`∂y/∂x = ∂F(x)/∂x + I`（`I` 为单位矩阵）。那个恒等项保证了梯度**至少有一条路径以原值回传**，不会被连乘衰减到零。这是最常被引用的解释。
2. **优化目标被简化**。若某层的最优变换就是「什么都不做」，原始形式需要把 `F(x)` 训练成恒等映射（困难），残差形式只需把 `F(x)` 训练成零（容易，权重衰减会自然把参数推向零）。**深层网络的冗余层因此变得容易优化而非有害。**
3. **集成视角**。展开后，一个 N 层残差网络的输出可以写成所有中间层输出之和，等价于大量浅层路径的隐式集成。这解释了残差网络对单层故障的鲁棒性。

**在 Transformer 中的位置**：`kn-0006` 的每个子层都被 `残差 + LayerNorm` 包裹。原论文对此的处理是：

```text
LayerNorm(x + Sublayer(x))
```

这一组合是 Transformer 能堆叠到数十层乃至上百层的必要条件。**没有残差连接，`kn-0005` 的自注意力再优秀也无法构成深层模型。**

> **本知识点不依赖 NLP 前置**：残差连接源自计算机视觉的 ResNet，其思想与具体模态无关。因此 `prerequisites` 为空，可安排在路线早期，与 `kn-0001` 并行学习。这是本知识库中**少数不依赖 `kn-0001` 的知识点**，体现了依赖图不总是树状串行的。
