## 一、领域范围声明

| 项 | 内容 |
| --- | --- |
| **L1 领域** | 自然语言处理 |
| **聚焦说明** | 收敛到「**深度序列建模与 Transformer 架构**」这一细分主线，而非泛化的自然语言处理 |

## 四、依赖关系概览

依赖图的完整边表以 `knowledge/domains/_graph.json` 为准（由脚本导出至 `data/route/`）。此处给出结构性观察：

### 4.1 入度为 0 的起点（5 个）

`kn-0001`、`kn-0008`、`kn-0009`、`kn-0014`、`kn-0015`

> **口径声明**：本节的「起点」在 `prerequisite_of` 与 `extends` 构成的子图上计算 —— 即「**没有任何前置要求、可以直接开始学**」的知识点。`related_to` 是对称的弱关联，不构成前置，因此**不计入入度**。判定命令：

```bash
python scripts/check_knowledge_units.py
# 起始节点（无前置）：kn-0001, kn-0008, kn-0009, kn-0014, kn-0015
```

> **这一点很重要**：`kn-0008`（残差连接）与 `kn-0009`（层归一化）源自计算机视觉与循环网络，其思想与模态无关，因此不依赖 `kn-0001`；`kn-0015`（自适应优化器）同理，是纯优化方法的独立起点。**这意味着学习者可以并行开启多条线，路线不必是单链。** 路线生成时若强行线性化，会拉长总工期且不符合知识间的真实关系。

### 4.2 汇点（出度为 0 的终点，7 个）

`kn-0002`、`kn-0007`、`kn-0010`、`kn-0012`、`kn-0013`、`kn-0014`、`kn-0015`

> **口径声明**：本节的「汇点」同样只在 `prerequisite_of` 与 `extends` 子图上计算 —— 即「**没有任何后继依赖它**」的知识点。因此 `kn-0002` 虽然有一条 `kn-0002 → kn-0003` 的 `related_to` 出边，仍计为汇点；同理 `kn-0007`、`kn-0010` 也各有 `related_to` 出边但无前置后继。
>
> 若改按「所有边类型（含 `related_to`）的出度」计算，汇点会缩减为 `kn-0002` / `kn-0012` / `kn-0014` 三个，与上表不同。**两个口径都自洽，但本文统一采用前者（只数前置边），与本库「起点/汇点描述学习路线的头尾」这一用途一致。** 该口径已写入 `schemas/knowledge-graph.schema.json`，并由 `check_knowledge_units.py` 强制校验 `_graph.json` 与源数据一致。

### 4.3 关键路径

```text
kn-0003 → kn-0004 → kn-0005 → kn-0006 → kn-0011 → kn-0012
（循环神经网络 → 注意力 → 自注意力 → Transformer → 规模化 → 对齐）
```

**这是本库最长的依赖链，也是整个学习路线的骨架。** 其中 `kn-0004 → kn-0005` 与 `kn-0005 → kn-0006` 是最关键的两条因果边：

- `kn-0004 → kn-0005`：注意力从「RNN 的辅助组件」升级为「唯一核心机制」
- `kn-0005 → kn-0006`：核心算子组装为可堆叠架构

### 4.4 多前置节点（路线上的汇聚点）

| 知识点 | 前置数 | 前置列表 | 说明 |
| --- | --- | --- | --- |
| `kn-0006` | **3** | `kn-0005`、`kn-0008`、`kn-0009` | 全库最多。三者缺一不可 |
| `kn-0002`、`kn-0003` | 各 1 | `kn-0001` | 表示学习与序列建模在此分叉 |
| `kn-0010`、`kn-0011`、`kn-0013` | 各 1 | `kn-0006` | 三个分支：微调路线、规模化路线、跨模态路线 |

> `kn-0006` 是**单点汇聚**：图上三条边汇入。路线生成必须保证这三个前置全部排在它之前。这是本库对路线生成能力最直接的一次考验 —— 若生成的路线把 `kn-0006` 排在 `kn-0008` 之前，说明依赖建模未被正确使用。

### 4.5 环检测结论

已通过拓扑排序验证：**15 个节点全部可排序，无循环依赖**（SPEC-06 §5.4）。校验命令：

```bash
python scripts/check_knowledge_units.py
```
