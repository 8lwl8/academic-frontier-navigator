# Transformer 完整架构

## 一句话概括

把自注意力、位置编码、残差连接与层归一化组装为可堆叠的编码器-解码器结构，形成第一个完全不含循环与卷积的序列转换框架。

## 核心内容

`kn-0005` 给出了自注意力这一核心算子，但它单独无法构成可用模型 —— 它丢掉了位置信息，且深层堆叠会遭遇训练困难。**Transformer** 的价值在于把若干组件组装为可稳定堆叠的架构。

**编码器-解码器整体结构**：

```text
编码器（N=6 层）
  └── 每层：多头自注意力 → 残差 + LayerNorm → 前馈网络 → 残差 + LayerNorm

解码器（N=6 层）
  └── 每层：掩码多头自注意力 → 残差 + LayerNorm
              → 交叉注意力（Q 来自解码器，K/V 来自编码器）→ 残差 + LayerNorm
              → 前馈网络 → 残差 + LayerNorm
```

**四个关键设计决策**：

1. **位置编码**（弥补 `kn-0005` 的结构性代价）。由于自注意力对位置置换不变，必须显式注入位置信息。原论文采用正弦/余弦函数生成固定编码：偶数维用 sin，奇数维用 cos，不同维度对应不同频率。选择三角函数而非可学习嵌入的理由是它**允许外推到训练时未见过的更长序列**。后续主流改为旋转位置编码（RoPE）或相对位置编码，但解决的问题相同。

2. **残差连接 + 层归一化**（见 `kn-0008`、`kn-0009`）。残差让梯度可以绕过子层直接回传，使数十层的堆叠成为可能；LayerNorm 稳定了各层的激活分布。原论文采用**后置归一化**（Post-LN，即 `LayerNorm(x + Sublayer(x))`），后续研究发现**前置归一化**（Pre-LN）训练更稳定，几乎成为大模型标配。

3. **掩码注意力**（仅解码器）。解码器生成时必须防止看到未来的词，否则模型会直接抄答案。做法是在 softmax 前把「未来位置」的注意力得分置为 −∞，使归一化后权重为 0。

4. **前馈网络**。每个位置独立经过同一个两层 MLP，中间维度通常是模型维度的 4 倍。它的作用是**在每个位置上做非线性变换** —— 注意力负责跨位置混合信息，前馈网络负责在每个位置内部加工信息，两者分工明确。

**为什么这一架构能取代 RNN**：并行性。RNN 的第 t 步依赖第 t-1 步，无法利用 GPU 的并行算力；Transformer 的所有位置同时计算，使得在相同硬件上用大得多的数据训练大得多的模型成为可能。**这是「大模型时代」得以开启的直接技术前提。**

## 与学习路线的关联

前置知识点（**注意：本知识点有三个前置，这是全库中最多的**）：

- `kn-0005`（自注意力）—— 核心算子
- `kn-0008`（残差连接）—— 深层堆叠的前提
- `kn-0009`（层归一化）—— 训练稳定性的前提

> 依赖说明：这三个前置缺一不可。仅有自注意力而无残差连接，6 层以上即难以训练；仅有残差而无归一化，训练后期激活值会漂移。**路线生成时须保证三者都排在本知识点之前。**

后继知识点：`kn-0010`（预训练语言模型范式）—— 把完整架构用于大规模无监督预训练。

> 建议验收标准：能从零写出一个两层 Transformer 编码器并通过一个玩具任务（如序列反转），同时能解释每个组件去掉后会发生什么。
